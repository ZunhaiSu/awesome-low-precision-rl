# Sources and scope

The survey covers twenty-nine contributions: nineteen core methods or systems, nine supporting studies, and one exploration boundary case. Conference and preprint versions count once. General PTQ, low-precision pretraining, unrelated generation modalities, and speculative-drafter acceleration fall outside the focal scope.

Source selection combines targeted searches for quantized rollout, low-precision LLM RL, and training–inference mismatch with backward citation tracing and primary-text examination. The collection is a narrative review; relevance follows the learner--sampler problem rather than keyword occurrence alone.

The [catalog](CATALOG.md) records complete titles, authors, first-publication dates, source versions, numerical regimes, and discussion locations. QeRL, QuRL, and QaRL use formal publication records. Preprint and proceedings title changes do not create separate contributions.

[Source-linked findings](EVIDENCE.md) retain the setting and comparison conditions of all nineteen core studies. HiFloat4 simulates FP4 arithmetic; QATFactory uses native NVFP4 rollout with BF16 training matmuls; Miles provides integrated system evidence. These results concern different execution regimes.

Empirical findings are taken from the primary studies. Foundational methods and neighboring surveys appear in the bibliography without entering the focal count.
